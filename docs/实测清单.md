# 女仆军团 · 实测清单

> 游戏启动很慢，所以本清单**一次走完**。按顺序做，勾掉一项算一项。
> 对应版本：1.1.1

---

## 0. 开测前（必须）

- [ ] **完全退出游戏**再重新启动 —— 换过 jar，运行中的实例读不到新代码
- [ ] 进游戏后 **选项 → 控制 → 女仆军团**，给「一键召唤/收回」**绑一个键**
      （它**默认不绑**，不绑就没法测最关键的功能）
- [ ] 确认「打开女仆军团」还是 `.`
- [ ] 背包里备好复活材料：**青金石、金锭、红石、铁锭、煤炭 各 1**

> 建议用一个新世界或先备份，避免测试弄乱主存档。

---

## 1. 面板基本操作

- [ ] `.` 能打开面板，`Esc` 能关
- [ ] 搜索框能过滤（输入名字片段）
- [ ] **全选 / 反选 / 清空** 三个按钮正常
- [ ] **只看收藏** 能切换
- [ ] 点最左边的星标：**能收藏**，且该女仆**跳到最上面**
- [ ] 反复点「刷新」多次，**顺序每次都一样**（不会乱跳）
- [ ] 血量数字紧贴血条左侧，长名字被截断、**不压到血量**
- [ ] 如果有两只同名女仆，副标题的 **`#xxxx` 短 ID 不同**，能区分

## 2. 招募（御币）

- [ ] 手持**博丽御币**，`Shift+右键`一只女仆 → 提示加入军团，面板出现她
- [ ] 手持**东风谷御币**，同样能招募（两种都行）
- [ ] 对已加入的女仆再做一次 → 移出军团
- [ ] 驯服一只新女仆（用蛋糕）→ **自动加入**
- [ ] 未招募的女仆**不出现**在面板里

## 3. 一键召唤 / 收回 ← **最关键，至今没成功跑过**

- [ ] 勾选一只`在列`的女仆 → 点面板**「一键收回」** → 她消失，状态变`已收起`
- [ ] 勾选她 → 点**「一键召唤」** → 她**出现在你身边**
- [ ] 勾选 2~3 只，一次操作**全部生效**，提示「成功 N 只」
- [ ] **按快捷键**（你绑的那个）：
  - [ ] 有`已收起`的 → 变成召唤
  - [ ] 只有`在列`的 → 变成收回
  - [ ] **一个都没勾** → 提示「请先勾选」，**不会乱拉全部女仆**
- [ ] **🚩 重点回归**：勾选一只`未加载`且**强加载开着**的女仆，按快捷键
      → 应该是**召唤**（把她拉过来），**不是**报「收回失败」

## 4. 强加载

- [ ] 给一只女仆打开强加载开关 → 首次会弹**说明窗口**，确认后开关变`开`
- [ ] 带她走开很远（或去别的维度）→ 回面板，她变`未加载`
- [ ] 此时点**召唤** → **能把远处的她拉过来**（这就是强加载的作用）
- [ ] 关掉强加载后再试 → 应提示「无法召唤该女仆」（预期，不是 bug）

## 5. 阵亡与复活（不掉落是本模组的核心卖点）

> 先给女仆**穿好认的装备**：命名武器、几件护甲、**主副手**、**女仆背包**塞东西、**饰品栏**、
> **Curios 饰品**

- [ ] 让她死（打怪或 `/kill`）
- [ ] 👀 **死亡瞬间盯住她脚下**：**没有掉落物**、**没有墓碑方块**、**饰品也不许飞出来**
- [ ] 面板里她变成`阵亡`，红色徽章
- [ ] **阵亡行的强加载格显示 `-`**，鼠标移上去有说明
- [ ] 鼠标移到红色「阵亡」徽章 → **变绿、文字变「复活」**，弹出材料提示
- [ ] 点一下 → 她**当场**出现、满血
- [ ] **逐项检查装备**：护甲 / 主副手 / 女仆背包 / 饰品 / 隐藏栏 / 任务栏 / **女仆经验**
- [ ] **Curios 饰品**：复活后是否回到**原来那一格**（如果有装 Curios）
- [ ] **死亡次数只 +1**：连死两次应该是「第 2 次」，不是「第 4 次」
- [ ] 复活后**好感度 -2**（TLM 原生惩罚，**预期，不是 bug**）

### 对照组（同样重要）

- [ ] **未招募**的女仆死亡 → **应该正常生成墓碑**（本模组不接管她）

## 6. 持久化（退出重进）

- [ ] 退出游戏 → 重进同一世界
- [ ] 招募状态、收藏、强加载开关、已收起列表、阵亡记录 **全都还在**

## 7. 其他

- [ ] `/maidlegion list` 命令能列出你的女仆和状态
- [ ] **多人**（如果方便）：另一个玩家**不能**操作你的女仆
- [ ] 与整合包其他女仆模组共存正常（`万法皆通` / `女仆实用任务` / `sweeper_maid`）

---

## ⚠️ 这些是预期行为，不是 bug

| 现象 | 原因 |
|---|---|
| 复活后好感度 -2 | TLM 原生死亡惩罚，本模组**有意不改**（计划做进技能） |
| 阵亡次数累计不清零 | 设计如此，PK 未来「读条时长」的输入 |
| 阵亡行强加载显示 `-` | 本次改动：她没有实体，开关无意义。**设置会保留，复活后生效** |
| 未开强加载时无法召唤`未加载`的女仆 | 设计如此（不偷偷加载区块） |
| 墓碑仍然出现在**未招募**女仆身上 | 本模组只管军团内的女仆 |

## 🆘 出问题怎么反馈

**四种拒绝理由的提示各不相同**，把提示**原文**发来即可定位：

| 提示 | 含义 |
|---|---|
| 这不是你的女仆。 | 归属校验失败 |
| 她还没加入女仆军团。 | 没招募 |
| 她不需要复活。 | 她不是阵亡状态 |
| 材料不足：需要…… | 缺复活材料 |

配套日志：`logs/latest.log`（搜 `maid_legion` 或 `Maid Legion`）
