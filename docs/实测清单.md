- [ ] **完全退出游戏**再重新启动 —— 换过 jar，运行中的实例读不到新代码

- [ ] 进游戏后 **选项 → 控制 → 女仆军团**，给「一键召唤/收回」**绑一个键**

- [ ] 背包里备好复活材料：**青金石、金锭、红石、铁锭、煤炭 各 1**

- [ ] **只看收藏** 能切换

- [ ] 反复点「刷新」多次，**顺序每次都一样**（不会乱跳）
- [ ] 血量数字紧贴血条左侧，长名字被截断、**不压到血量**
- [ ] 如果有两只同名女仆，副标题的 **`#xxxx` 短 ID 不同**，能区分
- [ ] 🆕 底部现在是 **5 个按钮**：`打开女仆界面` `强化` `一键召唤` `一键收回` `刷新`

## 2. 招募（御币）

- [ ] 手持**博丽御币**，`Shift+右键`一只女仆 → 提示加入军团，面板出现她
- [ ] 手持**东风谷御币**，同样能招募（两种都行）
- [ ] 对已加入的女仆再做一次 → 移出军团
- [ ] 驯服一只新女仆（用蛋糕）→ **自动加入**
- [ ] 未招募的女仆**不出现**在面板里

## 3. 一键召唤 / 收回 ← **最关键**

- [ ] 勾选 1 只「在列」女仆 → 绑的键 → **她消失，变成「已收起」**
- [ ] 再按一次 → **她回到身边，变成「在列」**
- [ ] 勾选多只（3~5 只）一起 → 批量顺序执行，**不卡顿**
- [ ] 勾选 0 只时按键 → 提示「请先勾选」，**不报错**
- [ ] **勾选一只「已收起」的女仆**按召唤键 → 她**应该被放出来**（1.1.1 修过这里）
- [ ] **勾选一只「未加载」且没开强加载**的女仆 → 提示无法召唤，**不崩**

## 4. 阵亡与复活

- [ ] 让一只军团女仆被打死 → **不掉墓碑、不掉一地物品**，面板里变「阵亡」
- [ ] 聊天栏出现「%s 阵亡了，已由女仆军团接管」
- [ ] ⚠️ **重点：她的背包 / 饰品 / 手持物**复活后**一件不少**
      （1.1.1 修过一次严重 bug，1.2.0 动了 `MaidManagerService`，必须回归）
- [ ] 鼠标移到状态徽章 → 变成「复活」，点一下 → 她回来了
- [ ] 复活消耗了 青金石/金锭/红石/铁锭/煤炭 各 1
- [ ] 复活后她的**装备、Curios 饰品**都在，且饰品回到**原来那一格**
- [ ] 阵亡次数显示**只 +1**（不是 +2）
- [ ] 🆕 ⚠️ **好感度惩罚**：记住她死前的好感度，复活后看**是不是扣了 2**
      - 1.1.1 其实是**一点没扣**（快照早于 TLM 扣分），1.2.0 应恢复成扣 2
      - 用 `/maidlegion` 或 TLM 自己的界面看好感度

## 5. 🆕 强化面板 · 单体页

- [ ] 勾选**恰好 1 只**女仆 → 「强化」按钮**可点**
- [ ] 勾选 **0 只或 2 只以上** → 「强化」**灰显**
- [ ] 进面板能看到两行标题：**单体强化 / 全军强化**
- [ ] 9 项都能看到：名称、`Lv 0 / 100`、进度条、效果、下一级价格、`[升级]`
- [ ] 她的经验**足够**时点升级 → 经验减少、等级 +1、`Lv 1 / 100`、进度条**动了一点**
- [ ] **属性真的生效**：升几级「攻击力」后打怪，伤害**变高**
- [ ] **生命上限**：升级后最大血量**变大**（看面板血量或 TLM 界面）
- [ ] 经验**不够**时「升级」**灰显**

- [ ] **分段价格**：`Lv 19→20` 每级 20，`Lv 20→21` 跳到 **120**（可拿便宜的功能类测）
- [ ] 价格显示带千位分隔（如 `2,500`）
- [ ] 🆕 ⚠️ **重启游戏后等级还在**，且属性**没有翻倍**（叠加两次是典型 bug）
- [ ] 🆕 把「未加载」的女仆选中进面板 → 提示读不到、按钮全灰

## 6. 🆕 强化面板 · 全军页 + P 点仓库

- [ ] 不勾任何女仆，也能切到**全军强化**页（不被勾选锁住）
- [ ] 顶部看到 **TLM 钱包 / 军团仓库** 和进度条
- [ ] 钱包数字和 TLM 实际一致（上限显示 5.0）
- [ ] 手动捡几个 P 点 → 等 1 秒 → **多出的部分自动进仓库**（自动转入默认开）
- [ ] 点 **自动转入** → 变成「关」→ 再捡 P 点钱包**不再被抽走**
- [ ] 点 **存入全部** → 钱包归 0，仓库增加
- [ ] 点 **取出全部** → 仓库减少，钱包**充到 5.0（不多不少）**
- [ ] 钱包已满时点取出 → 提示「钱包已满」
- [ ] 仓库里的 P 点**够**时点「购买」→ 扣款、变「已拥有」、按钮灰显
- [ ] P 点**不够**时「购买」灰显
- [ ] 🆕 **全军经验加成**：买了之后，女仆捡经验球**涨得更多**（约 2 倍）
- [ ] 🆕 **阵亡好感度全免**：买了之后，再让女仆死一次并复活 → **好感度不掉了**
- [ ] 🆕 重启后仓库余额和已购能力**都还在**

## 7. 🆕 飞行跟随（重点观察项）

- [ ] 买下「飞行跟随」能力
- [ ] 切**创造模式**，飞到高空 → 女仆**跟着飞上来**，不是在地上追
- [ ] 落地 → 女仆**恢复正常**，不再悬空
- [ ] ⚠️ **会不会和 TLM 的地面寻路打架**？（表现为女仆在空中抖动 / 抽搐）
      - 会的话把配置 `enableFlightFollow` 关掉，并反馈
- [ ] 没买能力时飞行 → 女仆**照旧在地上跑**（能力确实生效了）
- [ ] 距离超过约 32 格 → 女仆**放弃追随**，不会被猛地拽过来

## 🆕 1.2.0 已知风险点（测的时候重点盯）

| 风险 | 表现 | 处理 |
|---|---|---|
| ⚠️ **飞行跟随与 TLM 寻路打架** | 女仆在空中抖动 / 抽搐 | 关 `enableFlightFollow`，反馈 |
| ⚠️ **魔法伤害吃不到加成** | 万法皆通的部分法术（真伤）伤害没涨 | **已知盲区**，见 `TLM-P点与女仆成长机制.md` §7.2 |
| ⚠️ **枪械伤害** | TaCZ 子弹的 `getOwner()` 若不是女仆，加成不生效 | 反馈，改用 TaCZ 事件钩子 |
| ⚠️ **属性叠加两次** | 重启后攻击力翻倍 | 说明 transient 修饰符出了问题，**优先反馈** |
| ⚠️ **好感度惩罚** | 复活后没扣 2 | 说明补扣逻辑没跑到 |
| ⚠️ **自动转入抽干钱包** | TLM 祭坛因 power 不足用不了 | 配置调高 `autoDepositThreshold`，或点「取出全部」 |
